# إفصاح سلامة البيانات — Google Play (Data safety)

المصدر التقني: Supabase Auth + جداول المستخدم المرتبطة بـ `auth.uid()`، وتفضيلات محلية في المتصفح/الجهاز.

## البيانات التي تُجمع (عند إنشاء حساب أو استخدام الميزات)

| النوع | الغرض | مشاركة مع طرف ثالث؟ | يمكن طلب حذفها؟ |
|---|---|---|---|
| البريد الإلكتروني | إنشاء الحساب وتسجيل الدخول | لا (مضيف البنية: Supabase) | نعم عبر حذف الحساب |
| معرّف المستخدم | ربط المفضّلة وتقدّم الحفظ | لا | نعم |
| المفضّلة / الإشارات | مزامنة المحتوى المحفوظ | لا | نعم (CASCADE أو مسح محلي) |
| تقدّم البطاقات (`sr_reviews`) | مراجعة الحفظ | لا | نعم مع حذف الحساب |
| تفضيل الوضع الليلي والكثافة | تجربة واجهة | لا — محلي غالبًا | نعم (مسح الإعدادات) |
| رموز دفع الإشعارات (إن فُعِّلت) | تنبيهات الصلاة/المحتوى | مزوّد الدفع (APNs/FCM) | بإيقاف الإشعارات / حذف الحساب |

## ما لا نجمعه
- لا نبيع بيانات شخصية
- لا نتتبّع إعلاناتًا عبر التطبيقات
- لا نطلب جهات الاتصال أو الموقع الدقيق إلا لمواقيت الصلاة بموافقة المستخدم (إحداثيات للتقويم فقط)

## الاحتفاظ والحذف
- تُحذف صفوف المستخدم المرتبطة عند حذف حساب Auth (ON DELETE CASCADE في المخطط المعتمد).
- مسار ذاتي: `/delete-account` داخل التطبيق.
- طلب يدوي: Majlisilm.app@gmail.com

## التشفير والنقل
- HTTPS/TLS في النقل
- جلسات عبر Supabase Auth
