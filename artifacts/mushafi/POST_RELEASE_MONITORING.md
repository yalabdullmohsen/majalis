# Post-Release Monitoring Plan

## Version

`1.0.0+1`

## Monitoring Goals

بعد إطلاق الإصدار الأول، يجب مراقبة:

- أعطال بدء التشغيل.
- مشاكل صلاحية الميكروفون.
- مشاكل ملف القرآن.
- مشاكل ASR server عند المستخدمين الذين يفعلونه.
- مشاكل PDF.
- مشاكل التذكيرات.
- مشاكل بطء الشاشة.
- مشاكل iOS/Android platform-specific.

## Privacy Rules

- لا تجمع الصوت تلقائيا.
- لا تجمع نص القرآن.
- لا تجمع API keys.
- لا تجمع endpoints الخاصة بالمستخدمين إلا إذا أرسلها المستخدم يدويا.
- لا ترسل التشخيص تلقائيا.
- اجعل المستخدم ينسخ تقرير المشكلة ويرسله بنفسه.

## First 72 Hours

راقب خلال أول 72 ساعة:

- تقييمات المتجر.
- رسائل الدعم.
- crash reports إذا أضفت crash reporting لاحقا.
- أخطاء تثبيت التطبيق.
- مشاكل الصلاحيات.
- مشاكل شاشة التسميع.

## Weekly Review

كل أسبوع:

- راجع التقارير اليدوية.
- صنف المشاكل.
- حدد إن كانت تحتاج Hotfix.
- حدّث Known Issues.
- حدّث FAQ.
- جهز v1.0.1 إذا تكررت مشاكل حرجة.

## Severity Levels

### S0 - Critical

- التطبيق لا يفتح.
- crash عند بدء التسميع.
- ملف القرآن لا يعمل في الإصدار المنشور.
- خطأ خصوصية يؤدي لإرسال صوت بدون إذن.

### S1 - High

- الميكروفون لا يعمل على أجهزة كثيرة.
- PDF لا يتولد إطلاقا.
- شاشة النتيجة تنهار.
- إعدادات ASR تسبب crash.

### S2 - Medium

- ضعف تجربة المستخدم.
- رسائل خطأ غير واضحة.
- مشكلة جزء معين في Dashboard أو SRS.

### S3 - Low

- تحسين نصوص.
- تحسين UI.
- تعديل ترتيب أزرار.
- تحسين README أو store copy.
