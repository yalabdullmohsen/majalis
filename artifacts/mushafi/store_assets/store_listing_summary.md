# Store Listing Summary

## Arabic App Name

مصحفي - التسميع ومراجعة الحفظ

## English App Name

Mushafi - Quran Recitation Review

## Arabic Short Description

تطبيق يساعدك على مراجعة حفظ القرآن بالتسميع وخطة مراجعة ذكية.

## English Short Description

Review Quran memorization with recitation sessions and smart revision plans.

## Core Message

The app helps users review Quran memorization through structured recitation sessions, approximate technical feedback, and personal revision planning.

## Privacy Message

Microphone is used only during recitation sessions. Audio is not uploaded unless the user enables the advanced server engine and explicitly allows upload.

## Disclaimer Message

The app provides approximate technical feedback for memorization review. It is not a religious ruling or definitive judgment on recitation or tajweed.
