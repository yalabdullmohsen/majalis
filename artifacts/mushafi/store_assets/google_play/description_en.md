# Suggested App Name

Mushafi - Quran Recitation Review

# Short Description

Review Quran memorization with guided recitation, reports, and smart revision plans.

# Full Description

Mushafi helps users review Quran memorization through guided recitation sessions.

Choose a surah and ayah range, start a recitation session using the microphone, then review an approximate report showing words that may need revision, overall estimated accuracy, and suggested review areas.

## Features

- Select surah and ayah range.
- Voice-based recitation review.
- Clear session summary.
- Highlighted words that may need attention.
- Mistake review report.
- Recitation dashboard.
- Daily goals and streaks.
- Smart review plan.
- Spaced repetition review.
- Local reminders.
- PDF session report.
- Quran data integrity check.
- Privacy and feature limitations screens.

## Privacy

The microphone is used only when the user starts a recitation session.

Audio is not sent to an external server unless the user enables the advanced recitation engine and explicitly allows audio upload in the app settings.

The app can also work with on-device speech recognition when available.

## Quran Text Source

The Quran text is not generated by artificial intelligence. The app relies on a Quran data file included in the app. The publisher must ensure that the Quran text file is sourced from a trusted and properly licensed source before release.

## Important Notice

Recitation results are approximate technical aids for memorization review. They are not religious rulings, fatwas, or definitive judgments on recitation or tajweed.

For best results:
- Use a quiet environment.
- Select a short ayah range.
- Keep the microphone close.
- Review highlighted words after each session.
