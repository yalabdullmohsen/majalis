# Icon and Splash Checklist

## Icon

- [ ] App icon is original.
- [ ] No copyrighted assets.
- [ ] No misleading symbols.
- [ ] Looks clear at small size.
- [ ] Android adaptive icon configured.
- [ ] iOS icon sizes configured.
- [ ] No transparent background for iOS icon.

## Splash

- [ ] Splash is simple and readable.
- [ ] Uses app brand colors.
- [ ] Does not include long text.
- [ ] Works in light mode.
- [ ] Works in dark mode if supported.

## Brand Colors

- Background: #FBF7EF
- Primary: #A77A48
- Text: #11100E
