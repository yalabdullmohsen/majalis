# Screenshots Checklist

- [ ] Onboarding screen.
- [ ] Dashboard.
- [ ] Tasmee3 recitation range selection.
- [ ] Listening screen with live progress.
- [ ] Result screen with colored Quran page.
- [ ] Review plan / What to review today.
- [ ] Daily goals / streak.
- [ ] Privacy screen.
- [ ] Quran source / integrity screen.
- [ ] PDF report preview.

## Visual Guidelines

- Use real UI screenshots.
- Do not show private API keys.
- Do not show personal server URLs unless blurred.
- Do not show real user audio data.
- Use short Quran ranges.
- Avoid misleading claims like "perfect correction" or "certified tajweed".
- Add captions only if allowed and accurate.

## Arabic Captions Ideas

- راجع حفظك بخطوات بسيطة.
- اختر السورة ونطاق الآيات.
- تابع تقدم التسميع مباشرة.
- راجع مواضع تحتاج انتباها.
- خطط لمراجعتك اليومية.
- خصوصيتك واضحة وتحت تحكمك.

## English Captions Ideas

- Review your memorization step by step.
- Choose a surah and ayah range.
- Follow recitation progress live.
- Review highlighted areas.
- Build a daily revision habit.
- Privacy controls are clear.
