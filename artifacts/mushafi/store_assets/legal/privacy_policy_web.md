# Privacy Policy

Last updated: 2026-08-04

## Overview

Mushafi / مصحفي helps users review Quran memorization through recitation sessions, approximate technical feedback, and revision planning.

## Quran Text

The Quran text is not generated by artificial intelligence. The app uses a bundled Quran data file. The publisher is responsible for verifying that the Quran text file is from a trusted and properly licensed source.

## Microphone

The app uses the microphone only when the user starts a recitation session. The microphone is used to capture the user’s recitation for technical review and comparison with the Quran text included in the app.

## Audio Upload

Audio is not uploaded by default.

If the user enables the advanced server-based recitation engine and explicitly allows audio upload, the recorded audio may be sent to the configured server endpoint for speech recognition and technical analysis.

The user can disable server upload in the app settings.

## Local Data

The app may store the following data locally on the device:

- Recitation session history
- Approximate accuracy summaries
- Review plans
- Daily goals
- Streaks
- Reminder settings
- App settings
- ASR endpoint settings

## API Keys

If the user or publisher configures an API key for the ASR server, the app attempts to store it using secure storage when available.

## PDF Reports

PDF reports are generated locally on the device. The user chooses whether to share them.

## Notifications

The app may use local notifications to remind the user about daily recitation goals or review plans. Notifications can be disabled in the app settings or device settings.

## Data Sharing

The app does not sell user data.

Audio is not sent to an external server unless the user enables the advanced recitation engine and allows upload.

At the time of this draft review, no third-party analytics, advertising, or tracking SDKs were detected in the app dependencies. Local progress statistics remain on-device.

## Children and Families

If the app is offered to children or families, the publisher must review and comply with all applicable child privacy laws and store policies before release.

## Religious Disclaimer

The app provides approximate technical feedback to help with memorization review. It is not a religious ruling, fatwa, or definitive judgment on recitation, tajweed, or correctness.
