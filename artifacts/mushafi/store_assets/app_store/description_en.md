# App Name

Mushafi - Quran Recitation Review

# Description

Mushafi helps users review Quran memorization through structured recitation sessions.

Select a surah and ayah range, start reciting, and review a session report showing approximate accuracy and areas that may need revision.

## Key Features

- Select recitation range.
- Voice-based review.
- Clear session report.
- Smart revision plan.
- Daily goals.
- Local reminders.
- Spaced repetition.
- PDF reports.
- Quran file integrity check.
- Clear privacy controls.

## Privacy

The microphone is used only when a recitation session starts.
Audio is not sent to an external server unless the user explicitly enables this in settings.
The advanced server engine can be disabled, and on-device recognition can be used when available.

## Notice

Recitation results are approximate technical aids for review. They are not religious rulings or definitive judgments on recitation or tajweed.
