# App Review Notes

This app provides Quran memorization review tools.

## Microphone Usage

The app requests microphone permission only when the user starts a recitation review session. The microphone is used to capture the user's recitation for technical comparison with the Quran text included in the app.

## Audio Upload

Audio is not uploaded by default.

If the user enables the advanced server-based recognition engine and explicitly allows audio upload, the audio may be sent to the server endpoint configured by the user or publisher. This can be disabled in the app settings.

## Quran Text

The Quran text is not generated by artificial intelligence. It is loaded from a bundled Quran data file. The publisher is responsible for ensuring the file is from a trusted and licensed source.

## Religious Disclaimer

The app provides approximate technical feedback for memorization review. It does not provide religious rulings, fatwas, or definitive judgments on tajweed or recitation validity.

## Testing Path

1. Open the app.
2. Complete or skip onboarding.
3. Open Tasmee3 dashboard.
4. Start a recitation session.
5. Grant microphone permission.
6. Recite a short range.
7. Stop and review the session result.
8. Open privacy and limitation pages from the dashboard/settings.
