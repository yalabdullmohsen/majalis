# App Review Notes - Final

This app helps users review Quran memorization through structured recitation sessions.

Microphone permission is requested only when the user starts a recitation session. The microphone is used to capture the user's recitation for technical comparison with the Quran text bundled in the app.

Audio upload is disabled by default. If the user enables the advanced server-based recitation engine and explicitly allows audio upload, audio may be sent to the configured ASR server. This can be disabled in settings.

The Quran text is not generated by AI. It is loaded from a bundled Quran data file. The publisher is responsible for verifying the Quran source before release.

The app provides approximate technical feedback for memorization review. It does not provide religious rulings, fatwas, or definitive judgments on recitation or tajweed.

Testing steps:
1. Open the app.
2. Complete or skip onboarding.
3. Open the recitation dashboard.
4. Start a recitation session.
5. Grant microphone permission.
6. Recite a short ayah range.
7. Stop the session and review the result.
8. Open privacy, Quran source, and limitations pages.
