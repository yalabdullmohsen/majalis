# Launch Lock

## Version

`1.0.0+1`

## Status

Launch Lock Candidate.

## Purpose

هذا الملف يعني أن التطبيق دخل مرحلة القفل النهائي قبل الإطلاق.
لا يتم قبول أي ميزة جديدة قبل النشر إلا إذا كانت إصلاحا ضروريا لمشكلة حرجة.

## Locked Scope

الميزات المغلقة للإطلاق:

- التسميع الأساسي.
- اختيار السورة ونطاق الآيات.
- fallback عبر تعرف الجهاز عند توفره.
- محرك خادم اختياري غير مفعل افتراضيا.
- إعدادات الخصوصية لمحرك التسميع.
- Dashboard.
- SRS.
- التذكيرات.
- التقارير.
- PDF reports.
- فحص ملف القرآن.
- صفحات مصادر القرآن والحدود.
- الدعم والإبلاغ عن مشكلة.
- مواد Google Play و App Store.

## Locked Defaults

- رفع الصوت للخادم: غير مفعل افتراضيا.
- السماح بالإرسال الخارجي: غير مفعل افتراضيا.
- WebSocket Live: غير مفعل افتراضيا.
- Native PCM Streaming: غير مفعل افتراضيا.
- Debug diagnostics: غير مفعل افتراضيا.
- التطبيق يجب أن يعمل بدون خادم.
- التطبيق يجب أن يعمل بدون إنترنت للميزات المحلية.

## No-Go Conditions

لا ترفع التطبيق إذا تحقق أي شرط من التالي:

- فشل فحص ملف القرآن.
- عدد السور ليس 114.
- عدد الآيات ليس 6236.
- وجود آيات فارغة.
- وجود crash عند فتح التطبيق.
- وجود crash عند فتح شاشة التسميع.
- إرسال الصوت للخادم بدون موافقة المستخدم.
- ظهور API key في التشخيص.
- ظهور نص قرآن في التشخيص.
- وجود ادعاء بدقة مطلقة.
- وجود ادعاء بحكم شرعي على التلاوة.
- فشل flutter analyze.
- فشل flutter test.
- فشل pytest.
- فشل release_check.
- وجود TODO حرج قبل الإطلاق.

## Allowed Changes After Lock

مسموح فقط:

- إصلاح crash.
- إصلاح خصوصية.
- إصلاح خطأ في ملف القرآن أو assets.
- إصلاح build failure.
- إصلاح اختبار فاشل.
- تحسين نص تحذيري دون تغيير السلوك.
- تحديث وثائق المتجر أو الخصوصية.

## Forbidden Changes After Lock

ممنوع:

- إضافة ميزة جديدة.
- تفعيل WebSocket افتراضيا.
- تفعيل PCM افتراضيا.
- تفعيل إرسال الصوت افتراضيا.
- تغيير ملف القرآن دون مراجعة كاملة.
- تغيير بنية التخزين المحلي.
- إضافة SDK تتبع أو إعلانات دون تحديث الخصوصية.
- تغيير Claims المتجر إلى عبارات أقوى من السلوك الحقيقي.
