# Security — مصحفي / Tasmee3 ASR

## تطبيق Flutter

- لا تضع مفاتيح API في الكود المصدري؛ استخدم إعدادات المستخدم أو dart-define محليا للتطوير فقط.
- لا تسجل نص القرآن أو التسجيلات الصوتية في سجلات الإنتاج.
- fallback تعرف الجهاز يبقى متاحا إذا فشل الخادم.

## خادم ASR

- فعّل المصادقة (API key) في الإنتاج.
- استخدم HTTPS / WSS.
- فعّل rate limiting وحدود حجم/مدة الصوت.
- احذف الملفات المؤقتة بعد المعالجة.
- لا تخزن الصوت بشكل دائم.

راجع `server/tasmee3_asr/` و`PERFORMANCE_CHECKLIST.md`.
