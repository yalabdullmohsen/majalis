# Microphone Rejection Response Template

## Response Template - English

Hello,

The microphone permission is required for the core recitation review feature.

The app requests microphone access only when the user starts a recitation session. The microphone is used to capture the user's recitation so the app can provide approximate technical feedback and help with memorization review.

The app does not record in the background, and the user can cancel or deny microphone permission. If permission is denied, the app shows a clear message and does not crash.

We have clarified the microphone usage in the permission prompt, App Review Notes, and privacy policy.

Thank you.
