# Post-Submission Checklist

## After Google Play Submission

- [ ] Record submission date.
- [ ] Record track.
- [ ] Record version.
- [ ] Save testing link.
- [ ] Monitor review status.
- [ ] Monitor tester feedback.
- [ ] Log any rejection.
- [ ] Do not submit hotfix without classification.

## After App Store Submission

- [ ] Record submission date.
- [ ] Record build number.
- [ ] Save TestFlight status.
- [ ] Monitor App Review messages.
- [ ] Log any rejection.
- [ ] Do not change privacy answers without reviewing actual behavior.

## If Approved

- [ ] Update SUBMISSION_STATUS.md.
- [ ] Update launch announcement.
- [ ] Prepare support response.
- [ ] Monitor first 72 hours.
- [ ] Update KNOWN_ISSUES.md.

## If Rejected

- [ ] Copy reviewer message.
- [ ] Classify severity.
- [ ] Use response template.
- [ ] Fix only necessary issue.
- [ ] Bump build number if new binary needed.
- [ ] Run release checks.
- [ ] Resubmit.
