# Release Candidate Test Plan

## 1. Startup

- [ ] التطبيق يفتح بدون إنترنت.
- [ ] التطبيق يفتح بدون إعداد خادم.
- [ ] التطبيق لا ينهار إذا إعدادات ASR فارغة.
- [ ] Onboarding يظهر لأول استخدام.
- [ ] Dashboard يظهر بعد Onboarding.

## 2. Quran Integrity

- [ ] ملف القرآن موجود.
- [ ] فحص القرآن ينجح.
- [ ] عدد السور 114.
- [ ] عدد الآيات 6236.
- [ ] لا توجد آيات فارغة.
- [ ] صفحة مصادر القرآن تعمل.
- [ ] صفحة حدود التسميع تعمل.

## 3. Recitation Local Flow

- [ ] فتح شاشة التسميع.
- [ ] اختيار سورة ونطاق قصير.
- [ ] عرض النص المتوقع.
- [ ] بدء التسميع.
- [ ] طلب صلاحية الميكروفون في السياق الصحيح.
- [ ] رفض الميكروفون لا يسبب crash.
- [ ] إيقاف وتحليل يعمل.
- [ ] النتيجة تظهر.
- [ ] إعادة التسميع تعمل.

## 4. Privacy

- [ ] تنبيه الخصوصية يظهر قبل التسجيل.
- [ ] سياسة الخصوصية يمكن فتحها.
- [ ] رفع الصوت للخادم غير مفعل افتراضيا.
- [ ] إرسال الصوت يحتاج موافقة المستخدم.
- [ ] API key لا يظهر في التشخيص.
- [ ] التشخيص لا يحتوي صوتا.
- [ ] التشخيص لا يحتوي نص القرآن.

## 5. ASR Settings

- [ ] إعدادات محرك التسميع تفتح.
- [ ] الوضع الافتراضي لا يرسل الصوت للخادم.
- [ ] endpoint فارغ لا يسبب crash.
- [ ] endpoint خاطئ يظهر خطأ واضح.
- [ ] WebSocket غير مفعل افتراضيا.
- [ ] Native PCM غير مفعل افتراضيا.
- [ ] fallback يعمل عند تعطيل الخادم.

## 6. Dashboard and SRS

- [ ] Dashboard يفتح.
- [ ] الهدف اليومي يظهر.
- [ ] مراجعة اليوم تظهر بعد وجود بيانات.
- [ ] السجل يفتح.
- [ ] خطة المراجعة تفتح.
- [ ] الإنجازات تفتح.
- [ ] SRS يتحدث بعد جلسة.

## 7. Reports

- [ ] نسخ تقرير الجلسة يعمل.
- [ ] PDF report يتولد.
- [ ] مشاركة PDF تعمل.
- [ ] PDF لا يحتوي معلومات حساسة.

## 8. Reminders

- [ ] إعدادات الهدف تفتح.
- [ ] تفعيل تذكير لا يسبب crash.
- [ ] رفض صلاحية الإشعارات لا يسبب crash.
- [ ] اختبار الإشعار يعمل إذا الصلاحية ممنوحة.

## 9. Support

- [ ] صفحة حول التطبيق تعمل.
- [ ] رقم الإصدار يظهر.
- [ ] صفحة الدعم تعمل.
- [ ] نسخ التشخيص يعمل.
- [ ] إعادة ضبط بيانات التسميع تعمل.
- [ ] ملف القرآن لا يحذف عند إعادة الضبط.

## 10. Offline

- [ ] Dashboard يعمل بدون إنترنت.
- [ ] السجل يعمل بدون إنترنت.
- [ ] SRS يعمل بدون إنترنت.
- [ ] PDF يعمل بدون إنترنت.
- [ ] فحص القرآن يعمل بدون إنترنت.
- [ ] الخادم المتقدم فقط يحتاج إنترنت.

## 11. Store Readiness

- [ ] وصف Google Play جاهز.
- [ ] وصف App Store جاهز.
- [ ] Privacy drafts جاهزة.
- [ ] Screenshots checklist جاهز.
- [ ] Store checklist جاهز.
- [ ] لا توجد ادعاءات مضللة.
