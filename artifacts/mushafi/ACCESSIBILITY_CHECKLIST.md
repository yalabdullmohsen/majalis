# Accessibility Checklist

## RTL

- [ ] كل شاشات Tasmee3 تستخدم Directionality RTL.
- [ ] النصوص العربية مصفوفة بشكل صحيح.
- [ ] الحقول التقنية مثل Endpoint تستخدم LTR.

## Text

- [ ] حجم النص واضح.
- [ ] نص الآيات واضح ومقروء.
- [ ] رسائل الخطأ مفهومة.
- [ ] لا توجد نصوص إنجليزية للمستخدم العام إلا للحقول التقنية.

## Buttons

- [ ] كل زر مهم له label واضح.
- [ ] الأيقونات المهمة معها نص.
- [ ] زر بدء التسميع واضح.
- [ ] زر إيقاف وتحليل واضح.

## Colors

- [ ] لا يعتمد التطبيق على اللون وحده لشرح الخطأ.
- [ ] توجد نصوص تشرح معنى الألوان.
- [ ] التباين مقبول بين الخلفية والنص.

## Motion

- [ ] لا توجد حركات مزعجة.
- [ ] لا توجد animations تمنع الاستخدام.
