# Changelog

## 1.0.0+1

### Added

- ميزة التسميع Tasmee3.
- اختيار السورة ونطاق الآيات.
- التعرف الصوتي عبر الجهاز كخطة بديلة.
- محرك ASR متقدم اختياري عبر الخادم.
- Forced Alignment.
- Live Follow Along.
- نظام مراجعة متباعدة SRS.
- Dashboard للتسميع.
- أهداف يومية و Streak.
- تذكيرات محلية.
- تقارير PDF.
- فحص سلامة ملف القرآن.
- صفحات الخصوصية والحدود.
- اختبارات Flutter و Backend.
- CI workflow.

### Privacy

- لا يتم توليد نص القرآن بالذكاء الاصطناعي.
- لا يتم إرسال الصوت للخادم إلا بإذن المستخدم.
- تقارير PDF تنشأ محليا.

### Notes

- نتائج التسميع تقديرية ومساعدة تقنية، وليست حكما شرعيا على التلاوة.
