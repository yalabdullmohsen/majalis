# Feature Freeze

تم تجميد الميزات الأساسية لميزة Tasmee3 قبل الإطلاق.

## الميزات المشمولة

- التسميع الأساسي.
- محرك تعرف الجهاز fallback.
- محرك ASR المتقدم عبر HTTP.
- WebSocket Live ASR اختياري.
- Native PCM Streaming اختياري.
- Forced Alignment.
- Live Follow Along.
- SRS.
- Dashboard.
- الأهداف اليومية.
- التذكيرات.
- تقارير PDF.
- فحص ملف القرآن.
- صفحات الخصوصية والحدود.

## ممنوع قبل الإطلاق

- إضافة ميزة كبيرة جديدة.
- تغيير بنية النص القرآني.
- تغيير طريقة التخزين بدون migration.
- تعطيل fallback.
- إزالة أي تحذير خصوصية.
- استخدام نص قرآن مولد بالذكاء الاصطناعي.
