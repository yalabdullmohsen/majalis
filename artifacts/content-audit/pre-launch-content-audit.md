## تصنيف شرعي مرجعي (للمواد التي مُسّت)

| المعلومة | التصنيف |
|---|---|
| ذكر آزر أباً لإبراهيم (الأنعام 6:74) | قرآن صريح |
| الخلاف في تفسير اسم آزر (علم/لقب/…) | مختلف فيه / تفسير معتبر |
| الثناء على ذي الكفل بالصبر | قرآن صريح |
| نبوّة ذي الكفل | مختلف فيه (مع ميل كثير من المفسرين) |
| حكمة لقمان ووصيته | قرآن صريح |
| نبوّة لقمان | مختلف فيه — لا يُجزم |
| قصة ذي القرنين والسد | قرآن صريح |
| تعيين ذي القرنين بالإسكندر | غير موثق / مختلف فيه — لا يُجزم |
| هاروت وماروت في بابل | قرآن صريح (2:102) — بلا إسرائيليات مضافة |
| مواقع الأمم على الخريطة | قول تاريخي محتمل — تقريبي / لا يُجزم به |

## اختبارات الانحدار المضافة

- `pnpm run test:pre-launch-content-audit`
- مدمج في `test:religious-content` (وبالتالي `test:regression`)

تفشل عند:
- ظهور «رابط القراءة»
- ظهور «موثّقة بالأدلة» في مصادر الفقه المفحوصة
- غياب آزر
- غياب/تلوث عنوان `/nations` أو `/quran/people` أو `/prophets` بعنوان الرئيسية
- ظهور `undefined`/`null`/`TODO`/`Esc للقائمة` في نطاق المفحوص
- استخدام «قيد المراجعة الشرعية» كوصف تسويقي في `fiqh-hub-topics` (صفحة المنهجية مستثناة عمداً)
