# أصوات الأذان الكاملة (تشغيل داخل التطبيق)

هذه الملفات للأذان الكامل عبر HTMLAudio + AVAudioSession `.playback`.
أصوات الإشعارات القصيرة (≤٣٠ث) موجودة في `ios/App/App/Sounds/adhan-short-*.caf`.

| ملف | الاستخدام |
|---|---|
| adhan-makkah-full.m4a | أذان مكة (مقطع AAC عالي الجودة ~٢٨ث) |
| adhan-madinah-full.m4a | أذان المدينة |
| adhan-egypt-full.m4a | الأذان المصري |
| adhan-haram-full.m4a | أذان الحرم |
| adhan-soft-alert.m4a | تنبيه لطيف بدون أذان |
| adhan-aqsa-full.mp3 | أذان الأقصى |
| adhan-makkah-fajr.mp3 | فجر مكة بالتثويب |
| adhan-takbeerat-short.mp3 | تكبيرات قصيرة للمعاينة / fallback |

ملاحظة: الملفات القديمة `*-full.mp3` بمعدل ٨kbps كانت شبه غير مسموعة على iOS — استُبدلت بـ m4a.
