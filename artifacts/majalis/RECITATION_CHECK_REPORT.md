# تقرير الوحدة ٤٠ — تصحيح التلاوة بالميكروفون

**الفرع:** `cursor/recitation-check`  
**الوسم:** `safe:ui`  
**التاريخ:** 2026-08-11

## ١) الوضع قبل الوحدة

| بند | الحالة |
|---|---|
| زر الميكروفون في شريط المصحف | موجود → يفتح `/quran/recitation-test-ai` |
| تمييز الكلمات الصحيحة | موجود (`InteractiveMushafReveal`) |
| إيقاف عند الخطأ + اقتراح لطيف | جزئي — اللطيف بلا بطاقة ولا إيقاف |
| تلقين صوتي للكلمة المتوقعة | غير موجود |
| تقرير → تقدّم الحفظ (وحدة ١٤) | غير موجود (سحابة فقط لمسجّل الدخول) |
| `NSMicrophoneUsageDescription` | موجود عربيًا في Info.plist |
| تعارض جلسة الصوت | مسار موجود جزئيًا |

## ٢) ما نُفّذ

1. **سياسة لطيفة:** عند الخطأ → `needs_repeat` + بطاقة تصحيح + `softPause` (إيقاف ميكروفون مؤقّت بلا تأنيب).
2. **تلقين:** زر «تلقين» يشغّل صوت آية الكلمة المتوقعة عبر everyayah مع إيقاف التسجيل أولًا.
3. **تقرير محلي → حفْظ:** `hifz-session-bridge` يحفظ عدد الآيات · مواضع التوقّف · نسبة الإتقان في `mj-quran-hifz-v1` بلا حساب.
4. **تسليم صوت:** `playback-handoff` يوقف التلاوة عند دخول التسميع ويستأنفها عند الخروج إن كانت تعمل.
5. **خصوصية:** توضيح «محلي أولًا» + سحب موافقة + عدم إرسال صوت لخوادم المجلس.
6. **صفر تسريب جلسة:** teardown لـ ASR عند unmount الصفحة.

## ٣) البوابات

| بوابة | النتيجة |
|---|---|
| هدف كمون التمييز ≤300ms | `MIC_LATENCY_TARGETS.buttonToCaptureMs = 300` + اختبارات mic-latency |
| صفر تسريب جلسة تسجيل | endSession + speech teardown عند المغادرة |
| استئناف التلاوة بعد الخروج | `resumePlaybackAfterTasmee` من لقطة محفوظة |
| Info.plist عربي | متحقّق في الاختبار |
| بوابات المصحف ٤ مقاسات | تُشغَّل مع الـPR |

## ٤) قرارات

- التلقين يشغّل **الآية كاملة** (لا مقطع كلمة) لعدم توفّر توقيت كلمة موحّد موثوق في المسار الحالي.
- الحفظ المحلي يعمل لزائر بلا حساب؛ السحابة تبقى اختيارية لمسجّل الدخول.
- لم يُغيَّر مسار إرسال الصوت لخوادم المجلس — ما زال صفرًا؛ OS ASR مُفصح عنه.

## ٥) متبقٍّ للجهاز

- اختبار فعلي بضوضاء ولهجات متعددة.
- قياس كمون تمييز حي على جهاز ≤300ms (الهدف مضبوط في الكود/البوابة).
