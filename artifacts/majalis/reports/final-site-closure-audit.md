# تقرير تدقيق الإغلاق النهائي — 2026-08-15

## المنهج

لم يُعدَّل شيء إلا إذا وُجد الادعاء فعليًا في الكود أو الصفحة. ما لم يوجد سُجّل «غير موجود».

## نتائج الفحص

| الادعاء | الحالة على main قبل الإصلاح | الإجراء |
|---|---|---|
| «موثّقة بالأدلة» في /fiqh | موجود في `fiqh-hub-topics.ts` و`generate-seo` و`RulingsView` | استُبدل بصيغة إحالة تدريجية |
| «المصدر: رابط القراءة» | موجود في `generate-seo.mjs` + prerender المكتبة | المصدر = اسم النطاق (مثل sunnah.com) أو «المصدر قيد الإضافة» |
| «قيد المراجعة الشرعية» على /methodology كحكم عام | موجود في نص الصفحة (شرح الأوسمة) | صِيغ ليخص المواد الفردية؛ meta/JSON-LD بلا العبارة |
| /nations و/quran/people homepage fallback | **موجود** — لم يكن هناك prerender | أُضيف SEO shell لكل فهرس و`:slug` |
| آزر في quran people | **غير موجود** (40 سجلًا) | أُضيف (41) مع الأنعام 6:74 |
| تنبيه ذي الكفل | **غير موجود** | أُضيف `cautionNote` |
| قصص الأنبياء — حشو/إسرائيليات | **غير موجود كمشكلة** — `prophets-content-quality` ناجح لـ 25 نبيًا | لا تعديل |
| الصفحة الرئيسية | لم يُطلب تغيير محتوى؛ لم تُلمس | — |

## الاختبارات المضافة

`pnpm run test:final-site-closure` يفشل عند:
- ظهور «المصدر: رابط القراءة»
- «موثّقة بالأدلة» في hub الفقه
- عنوان homepage لـ /nations أو /quran/people
- غياب آزر أو cautionNote لذي الكفل
- وجود العبارة في meta المنهجية كحكم صفحة
