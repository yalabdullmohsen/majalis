**التاريخ:** 2026-08-09  
**النطاق:** بصري بحت — بلا تغيير لنص القرآن أو الترقيم أو حدود الصفحات أو `SOURCE.json`.

## ملخص التغييرات

| العنصر | قبل | بعد |
|---|---|---|
| الخلفية | `#F7F0E4` تقريبًا | `#FCF8F1` + رموز زخرفة/ميدالية |
| الرأس | `الجزء · الحزب` + `سورة …` رمادي باهت | `الجزء N` + اسم مجرّد، ذهب نصّي `#8F6A35` |
| الذيل | خرطوش وسط فقط | حزب/ربع يمينًا + خرطوش ثابت الجهة |
| شارة السورة | شريط بيج مسطّح | `SurahBanner` SVG (أرابيسك + لوحة وسطى) |
| علامة الآية | مجسم QPC أحادي / حلقة ذهبية | ميدالية ذهبية + رقم هندي (خيار A بعرض المجسم) |
| الامتلاء | LH متغيّر + تثبيت علوي ≈72–76٪ رأس→ذيل | خط من العرض + فجوات ≤0.55×LH + حشو 40/60 |

## قرار هندسي: لون نص الرأس/الذيل

`--color-mushaf-gold: #B08D57` على `#FCF8F1` = **2.92:1** (يفشل WCAG AA).  
لذلك بقيت الزخرفة على `#B08D57`، بينما نص الرأس/الذيل يستخدم `--color-mushaf-meta: #8F6A35` (**≈4.63:1**) حتى تبقى بوابة التباين خضراء.

## خوارزمية الامتلاء

1. حجم خط موحّد = ملاءمة العرض فقط (بلا سقف ارتفاع اصطناعي).  
2. فجوات متساوية بين أبناء `.mf2-lines` بسقف `0.55 × ارتفاع السطر`.  
3. الفائض بعد السقف: 40٪ أعلى / 60٪ أسفل.  
4. ص1–2: بلا `scaleX`، محاذاة مركزية، تمركز رأسي + `translateY(-4%)` — **ممنوع تبعثر الفراغات لبلوغ البوابة**.

## ميدالية الآية

- **خيار A (المعتمد):** مجسم QPC مخفي يحجز العرض؛ SVG الميدالية فوقه.  
- **خيار B:** إن فُقد المجسم — تلوين ذهبي + قرص لوحة `::before`.  
- **سقوط إلى B في القياس الثابت:** 0 صفحات (المسار A مضمّن لكل نهاية آية QPC؛ الوضع Unicode يستخدم ميدالية بعرض em بلا مجسم).

قيم `data-mf2-fill` / بوابة Playwright تُقاس بعد النشر. التقدير الهندسي من المنطق الجديد:

| 3 | عادية 15 سطر | ≥90٪ | فجوات موزّعة حتى السقف |
