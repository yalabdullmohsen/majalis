# أصوات إشعارات الصلاة (iOS)

ضع الملفات التالية هنا ثم أضِفها إلى Xcode target → Build Phases → Copy Bundle Resources:

| الملف | الاستخدام |
|---|---|
| `prayer_quiet.caf` | تنبيه قبل الصلاة (هادئ) |
| `prayer_clear.caf` | دخول وقت الصلاة (أوضح) |
| `prayer_soft.caf` | تذكير خفيف بعد الصلاة |

بعد إضافة الملفات فعّل العلم في المصدر:

`PRAYER_CUSTOM_SOUNDS_ENABLED = true`

في `src/lib/prayer-notification-sounds.ts`.

بدون الملفات يبقى التطبيق على صوت النظام (`default`) ولا ينكسر البناء.

## مقاطع الأذان الكامل (iOS)

iOS يحدّ صوت الإشعار بـ ≈٣٠ ثانية ويجب أن يكون الملف في الحزمة.

اتفاق التسمية (بعد التقطيع المرخّص):

| الملف | المعنى |
|---|---|
| `adhan_<id>_gen_s1.caf` … `_s4.caf` | أذان عام، حتى ٤ مقاطع ≤٢٨ث |
| `adhan_<id>_fajr_s1.caf` … `_s4.caf` | أذان فجر بالتثويب فقط |

- اقطع عند مواضع طبيعية (بعد التكبير/الشهادتين) لا وسط كلمة.
- أضِف الملفات إلى Xcode → Copy Bundle Resources.
- الجدولة: `src/lib/adhan-ios-segments.ts` (فجوة = مدة المقطع السابق؛ إلغاء السلسلة عند فتح التطبيق).
