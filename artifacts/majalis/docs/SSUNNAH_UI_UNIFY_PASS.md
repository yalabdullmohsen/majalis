# جولة توحيد واجهة سُنّة — سجل التنفيذ

تاريخ البدء: 2026-09-11 · الفرع: `cursor/ssunnah-ui-unify-polish`

## الحصر (ملخص)

| الفئة | العدد التقريبي | ملاحظة |
|---|---:|---|
| شاشات `src/views` | ~211 | تشمل تفاصيل وأدوات وإدارة |
| صفحات `src/pages` | ~174 | مسارات منتج أساسية |
| مكوّنات DS جاهزة | AppCard / FeatureCard / ContentCard / ScreenShell | موجودة قبل الجولة |
| بطاقات قديمة (ui-card/mj-card/…) | مئات الاستخدامات | جُسرت عبر `ssunnah-card-unify.css` |
| هكس في CSS صفحات | آلاف | دين طويل الأمد — ترحيل تدريجي للرموز |

## P0 المنفَّذ في هذه الدفعة

1. إزالة عبارات «جارٍ/جاري تحميل…» من واجهة المستخدم واستبدالها بهيكل/`تحديث…` سياقي أو هيكل صامت.
2. `LazyRouteFallback` بلا نص ظاهر (aria فقط).
3. رموز دلالية منتج: `ssunnah-semantic-tokens.css`.
4. جسر توحيد بطاقات: `ssunnah-card-unify.css`.
5. عناوين أقسام الإعدادات أوضح وظيفيًا.
6. توسيع بوابة `loading-ux-gates` لمنع رجوع صيغ التحميل.

## لم يُكتمل بعد (موانع إطلاق جزئية بصرية)

- ترحيل كل ملفات `styles/pages/*.css` من الهكس إلى الرموز.
- ربط كل الشاشات بـ ScreenShell صراحةً.
- مراجعة جهاز حقيقي TestFlight لكل تبويب.
- حذف الطبقات القديمة بعد اكتمال الترحيل 100٪.

## حماية شرعية

- لا تعديل على نص قرآني/حديث/متون.
- المصحف مستثنى من جسور البطاقات عبر `:not([data-scripture])` و`.mushaf`.
