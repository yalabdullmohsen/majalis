# استبعاد شرعي دائم — ليس طابور انتظار

آخر تحديث: 2026-09-07.

لا تُدرَج البنود أدناه في طابور مراجعة يوقف الدمج/النشر. تبقى **مستبعدة من الكتالوج العام** إلى أن يصدر قرار مالك صريح بالنشر.

| الموضوع | الحالة |
|---|---|
| لباس الشهرة المعاصر | منشور (`libas-shuhra-dawabit`) |
| زيارة النساء للقبور | منشور (محاذاة `ziyarat-qubur`) |
| الشبهات الغذائية المعاصرة | مستبعد — `internal_review_only` |
| نوازل الجهاد المعاصرة | مستبعد — `internal_review_only` |
