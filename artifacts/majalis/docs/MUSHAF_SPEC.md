## 2. جدول الثوابت

### شبكة الأسطر (`src/features/mushaf/mushaf-grid.json`)

- `referencePage`: **283**
- `slotCount`: **15**
- `baselinesPct`: `4.0 … 96.0` بخطوة `6.5714` (انظر الملف)
- `slotHeightPct`: **7.2**
- انحراف مسموح لخانات الآيات عن الشبكة: **≤ 2px**

### مقاييس الخط (`mushaf-baseline.json` على 390×844)

| ثابت | قيمة |
|------|------|
| fontSizePx | 24.382 |
| lineHeightEm | 1.35 |
| lineGapPx | 14.078 |
| topOffsetPct / bottomOffsetPct | 0 / 0 (صفحات عادية) |
| surahBannerHeightPx | 34.56 |
| fillPct (حبر/جسم) | ≈ 0.943 |

### نطاقات الشاشة (`layout-bands.ts` على 390×844)

أربعة نطاقات متتالية لا تتقاطع (فوق inset-bottom):

| نطاق | ثابت | ارتفاع مقيس (px) @390×844 | ≈٪ من 844 |
|------|--------|---------------------------|-----------|
| headerBand | `headerBandPx` | **38.25** | 4.53٪ |
| contentBand | مشتق → `.mf2-lines` | **701.75** | 83.15٪ |
| content→footer gap | `contentFooterGapPx` ≥12 | **12** محجوز (حبر→ذيل ≈56–58) | 1.42٪ |
| footerBand | `footerBandPx` | **40** | 4.74٪ |
| toolbarBand | `toolbarBandPx` | **52** (محجوز دائماً) | 6.16٪ |

- `mushaf-grid.json` يُشتق من **contentBand** (`.mf2-lines`) فقط — لا من ارتفاع الشاشة.
- عتبة الامتلاء بعد اعتماد contentBand: حبر داخل `.mf2-lines` ≈ **0.92–0.96** (مرجع ٢٨٣ ≈ 0.943 على contentBand).
- إظهار/إخفاء الشريط **لا يغيّر** خطوط الأساس ولا حجم الخط (إزاحة مقيسة = 0px).

### صفحتا الافتتاح (ص١–٢) — بلا إطار

- **لا إطار زخرفي** · لا أضلاع · لا ورود ركنية (`OpeningPageFrame` محذوف).
- فراغ علوي مقصود ≈**٢٨٪** من `contentBand` فوق الشارة (ليست عيبًا).
- أعلى الشارة: **٢٦٪–٣٠٪** من `.mf2-lines` (هدف ٢٨٪) — `OPENING_BANNER_TOP_PCT = 28`.
- البسملة تحت الشارة بفاصل ≥**20px**، مركزية بعرضها الطبيعي.
- الأسطر مركزية **بلا ملاءمة عرض** في ص١–٢.
- الهامش السفلي تحت آخر سطر مقصود (`OPENING_BOTTOM_MARGIN_PCT ≈ 12`).

### شريط الأدوات (وضع آية)

- موضع: داخل `toolbarBand` — `bottom: calc(var(--inset-bottom) + 6px)`
- الذيل فوقه: `bottom: calc(var(--inset-bottom) + var(--mpv-toolbar-band))`
- ظهور باللمس فقط؛ الحجز السفلي دائم سواء ظهر الشريط أم لا
- صفر تقاطع مع الشارة أو أسطر النص أو الخرطوش عند الإظهار

### الذيل — تناوب الخرطوش

- صفحة **فردية**: الخرطوش أسفل **اليمين** · وصف الحزب أسفل **اليسار**
- صفحة **زوجية**: الخرطوش أسفل **اليسار** · وصف الحزب أسفل **اليمين**

### لفّ الصفحة (خفيف)

- سحب يمينًا = التالية · يسارًا = السابقة · تتبع الإصبع **1:1**
- انحناء ≤**12°** · `perspective: 1200px` · ظل الطيّة عتامة ≤**0.18**
- اكتمال عند ≥**20٪** عرض أو سرعة ≥**0.4px/ms** · إفلات **260ms** · ارتداد **180ms**
- `transform`/`opacity` فقط · `prefers-reduced-motion` → تلاشٍ **150ms**
- لا يتعارض مع ضغط الآية المطوّل ولا مع شريط الأدوات الظاهر

### البسملة والشارة (صفحات عادية)

| قاعدة | قيمة |
|------|------|
| خانة البسملة | **مستقلة** عند `gap≥2` (`basmalaSlot = bannerSlot+1`) على خط أساس الشبكة — **ممنوع** إزاحتها من خط أساس الشارة |
| فجوة خانة واحدة (`gap=1`) | ١٨ صفحة في طبعة المدينة: خانة واحدة للشارة فقط — لا بسملة منفصلة (تفادي تراكب مع أول آية) |
| حجم بسملة غير الفاتحة | = حجم سطر الآية (±٢٪) · `font-size: 1em` · `font-weight: 700` |
| فاصل حبر عن أسفل الشارة | **≥ 20px** (تشغيلي ٢٢px) |
| ميدالية رقم على البسملة | **ممنوع** إلا الفاتحة (آية ١) |
| كثافة جناح الشارة | **٢٢٪–٣٨٪** من مساحة الجناح |
| عناصر الجناح | ميدالية + لفّات/شبكة + عقدة — بلا `<pattern>` مكرر |
| تصادم الحبر | **صفر** تقاطع بين مستطيلات حبر أي خانتين (`test:mushaf-ink-collision`) |

### الخرطوش والرأس

- مركز الخرطوش على المحور الأفقي للصفحة: **±2px**
- أسماء الرأس = السور التي **تبدأ** في الصفحة فقط (`surahsStartingOnPage`)

### ألوان `--color-mushaf-*` (أساسية)

| متغير | قيمة تقريبية |
|--------|----------------|
| `--color-mushaf-paper` | `#FAF7F2` / `#F7F0E4` |
| `--color-mushaf-ink` | `#1A1510` / `#14110E` |
| `--color-mushaf-gold` | `#B08D57` / `#8B6914` |
| `--color-mushaf-gold-strong` | `#A67C3D` |
| `--color-mushaf-numeral` | `#6B4E2A` |

تباين النص ≥ **4.5:1** نهارًا وليلًا.

## 3. قواعد التخطيط

1. **تموضع مطلق** على `MUSHAF_GRID.baselinesPct` — لا توزيع رأسي ديناميكي بعد تطبيق الشبكة.
2. **ملاءمة العرض** لأسطر الآيات المتوسطة فقط؛ **استثناءات بلا مطّ:**
   - البسملة
   - الشارة
   - آخر سطر سورة (عرض معروض ≤ ٩٠٪ إن كان المحتوى الطبيعي أقصر)
3. **الرأس:** فقط السور التي تبدأ في الصفحة؛ السورة المستمرة لا تُعرض في الرأس.
   (لا تُستورد صيغة رأس ص٢٨٣ القديمة «سورة … / الجزء · الحزب».)
4. **الخرطوش:** مركزي أفقيًا.
5. **صفحتا الافتتاح:** بلا إطار؛ شارة عند ≈٢٨٪ من contentBand؛ أسطر بلا مطّ؛ فراغ علوي مقصود.
6. **نطاقات متتالية:** contentBand تنتهي ≥12px قبل footerBand؛ toolbarBand محجوز دائماً؛ الإطار داخل contentBand؛ لا تقاطع شريط مع شارة/نص/خرطوش.

---

## 4. محظورات دائمة

1. **لا تستبدل مجسماً من خط QPC بعنصر مرسوم يدويًا.** الخط مصدر الشكل والرقم معًا.
2. **لا تعتمد بديلاً مبسّطًا عند تعذّر الزخرفة.** الأرضية الصلبة والنجمة المتفرّقة والسلاسل المكررة مرفوضة؛ إن لم تبلغ الكثافة فأعد الرسم.
3. **لا توزيع رأسي ديناميكي بعد تطبيق الشبكة:** ممنوع `space-between` / `justify-content` توزيعي أو حشو محسوب على حاوية الأسطر. تموضع مطلق فقط.
4. **لا `overflow: hidden` رأسيًا** على حاويات الأسطر أو الصفحة. أفقياً فقط عند الحاجة.
5. **لا إبلاغ بالتنفيذ بلا قياس.** كل بند يقابله رقم مقيس من اللقطة.
6. **لا مساس** بنص القرآن أو الترقيم أو حدود الصفحات أو `SOURCE.json` أو `mushaf≠1`.
