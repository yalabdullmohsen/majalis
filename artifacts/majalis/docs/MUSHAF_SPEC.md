## 2. جدول الثوابت (مرجع آية)

### صفحات عادية (≥٣) — ٪ من ارتفاع/عرض الشاشة

| عنصر | قيمة |
|------|------|
| خط أساس الرأس | **٨٫٣٪** — «الجزء N» يمين · أسماء السور (تبدأ أو تستمر) يسار بلا «سورة» |
| بداية كتلة النص | **١١٫٥٪–١٢٫١٪** |
| نهاية كتلة النص | **٩١٫١٪–٩١٫٨٪** |
| امتلاء رأسي مستهدف | **٧٩٪–٨٠٪** |
| هامش أفقي | **١٫٥٪ … ٩٨٫٤٪** · fit-to-width حافة لحافة |
| ذيل الخرطوش | **٩٣٫٢٪–٩٥٫٥٪** |
| وصف الحزب | يظهر **فقط** في صفحة بداية الحزب (٦٠ صفحة) · الحافة اليسرى |
| خرطوش عند بداية حزب | الحافة اليمنى (المقابلة للوصف) |
| خرطوش في غيرها | الحافة اليسرى · لا وصف حزب |

### صفحتا ١–٢

| عنصر | قيمة |
|------|------|
| أعلى الشارة | **٢٧٫٧٪** شاشة (≈٢٠٪ contentBand) |
| نهاية الكتلة | **٧٤٫٨٪** شاشة |
| ترتيب | رأس → فراغ → شارة بعرض كامل → بسملة → أسطر → فراغ → ذيل |
| بسملة | نفس المقاس؛ الفاتحة مرقّمة · البقرة غير مرقّمة |
| إطار زخرفي للصفحة | **ممنوع** |

### شبكة الأسطر (`mushaf-grid.json`)

- `slotCount`: **15**
- `baselinesPct`: `2.5 … 97.5` بخطوة `6.7857`
- `sideMarginPx`: **6** (≈١٫٥٪ على ٣٩٠)
- مسار رسم واحد: QPC · تحجيم عبر `--mushaf-scale` فقط · **ممنوع** مسار عثماني متدفق

### نطاقات الشاشة (`layout-bands.ts`)

أربعة نطاقات متتالية لا تتقاطع:

| نطاق | ملاحظة |
|------|--------|
| headerBand | خط أساس ٨٫٣٪ |
| contentBand | ≈٧٩–٨٠٪ من الشاشة |
| footerBand | خرطوش ٩٣٫٢–٩٥٫٥٪ |
| toolbarBand | تحت الذيل · صفر تقاطع مع الحبر/الذيل |

### تقليب الصفحة (آية)

- RTL مقسّم · بلا تمرير رأسي
- سحب يسار→يمين = التالية · عتبة **٢٥٪** أو سرعة **٠٫٥px/ms**
- حافة نقر **١٥٪** لكل جهة · settle **≤٢٥٠ms** · ease-out · `scroll-snap` أفقي بلا لف ثلاثي الأبعاد
- `prefers-reduced-motion` → تلاشٍ بسيط
- تحميل مسبق ±١

### شارة السورة

شارة مزخرفة (**islamic-light**): إطار ذهبي رفيع مزدوج · زخرفة هندسية جانبية خفيفة · لوحة عاجية وسطى باسم السورة. `data-ornament="islamic-light"`. تُحجز خانة كاملة في الشبكة وعرض ١٫٥٪→٩٨٫٤٪.

### أرقام الآيات

من محرف خط الصفحة `qpc-page-N` فقط · نفس حجم النص بلا خلفية ولا إطار ولا `transform` · التحديد تظليل خفيف على كلمات الآية (`ayah-active`) بلا حركة ولا تغيّر مقاس.

### شريط خطوط المصحف

داخل شيت الإعدادات فقط · يختفي بعد ١٫٥ ثانية من آخر تفاعل · **لا يظهر افتراضيًا** فوق الحبر.

شريط أدوات الصفحة العائم: مخفي افتراضيًا · يظهر بنقرة وسط الصفحة أو سحب رأسي للأعلى · يختفي بعد **٣٫٢ث** خمول أو عند بدء سحب تقليب.

### مقياس بصري

`--mushaf-scale` × `MUSHAF_OPTICAL_FONT_SCALE` (**١٫٠**) — مسار ملاءمة واحد بعد `document.fonts.ready`: بحث ثنائي على **قماش (canvas)** لحجم خط الصفحة بحيث أعرض سطر ≤ عرض الحاوية، ثم توزيع الكلمات بـ `flex` + `space-between` (امتلاء أفقي ≥ ٩٧٪ بالتعريف). الكاش بمفتاح `(page, containerWidth, family)` في الذاكرة و`localStorage`، وإعادة الحساب عبر `ResizeObserver` عند تغيّر العرض فقط. قيد أ: `overflowX === 0` لكل سطر. قيد ب: مجموع ارتفاعات الأسطر ≤ نطاق المحتوى.

### ألوان

| متغير | قيمة تقريبية |
|--------|----------------|
| ورقة | عاجي فاتح موحّد بلا بطاقة/ظل |
| حبر | أسود شبه صافٍ |
| ذهب | درجة واحدة للخرطوش/الزخرفة |
| رأس/ذيل | ذهبي ترابي أفتح |

تباين ≥ **4.5:1** نهارًا وليلًا.

## 3. قواعد التخطيط

1. تموضع مطلق على شبكة ١٥ · كل سطر `display:flex` بعرض ١٠٠٪: `space-between` للسطر الممتلئ، وتوسيط (`justify-content:center`) للصفحتين ١ و٢ كاملتين، ولآخر سطر سورة إذا لم يمتلئ، ولاسم السورة والبسملة.
2. fit-to-width عبر `fitPageFontSize` (canvas) لكل صفحة — لا تكبير/تصغير يدوي ولا `word-spacing` لمدّ الحروف.
3. `--mushaf-scale` = fontScale/20 مضروب في S المحسوب — مسار واحد.
4. إن ابتدأ حزب في الصفحة: وصف الحزب يساراً والخرطوش يميناً؛ وإلا الخرطوش يساراً ولا وصف حزب.
5. صفر تقاطع: رأس / نص / ذيل / شريط أدوات. `baselineShift === 0` عند إظهار/إخفاء الأدوات.
6. لا زر ظاهر على الصفحة افتراضياً. الأدوات بلمسة وسط الصفحة وتختفي بعد ٣٫٢ث.

---

## 4. محظورات دائمة

1. لا تستبدل مجسم QPC بعنصر SVG/HTML منفصل.
2. لا فرع كود يعيد الالتفاف عند أي مقياس خط.
3. لا شريط خطوط أخضر فوق الصفحة افتراضيًا.
4. لا `overflow: hidden` رأسي على حاويات الأسطر.
5. لا مساس بنص القرآن أو `mushaf≠1`.
