# مواصفة المصحف — مصدر الحقيقة الوحيد

> **قبل أي تعديل:** اقرأ [KNOWN_PITFALLS.md](../../../docs/KNOWN_PITFALLS.md) ثم هذا الملف.
> أي تعديل مستقبلي على عرض المصحف يبدأ بهذين المصدرين.
> الدليل على التنفيذ = رقم مقيس من اللقطة المرسومة، لا من قراءة الكود وحدها.

**النموذج الحالي (2026-08): تخطيط بسيط — بلا أرابيسك · بلا شبكة مطلقة · بلا خرطوش مزخرف · بلا إطار افتتاح.**

**لوحة منطقية:** 1000×1618  
**شبكة:** `data-mushaf-grid="flow"` · `grid-template-rows: repeat(15, 1fr)`  
**حجم الخط:** ثابت `S = mushaf-baseline.json → fontSizePx` (٢٤٫٣٨٢ على 390×844)  
**صفحات التجميد:** ١ · ٢ · ٣ · ٦٠٠ · ٦٠١ · ٦٠٢ · ٦٠٣  
**لقطات:** `docs/mushaf-baselines/` — تُحدَّث بعد اعتماد النموذج البسيط (البوابات البصرية تفحص الهيكل حتىئذٍ).

| صفحة | الدور |

| ٣ | أول صفحة عادية كاملة الأسطر |
| ٦٠٠–٦٠٣ | شارات متعددة / أواخر السور / رقم صفحة بسيط |

## 2. جدول الثوابت (نموذج بسيط)

### شبكة التدفق

- `slotCount`: **15** صفوف متساوية على `.mf2-lines`
- `data-mushaf-grid="flow"` · `data-board="1000x1618"`
- **ممنوع** `position:absolute` على `.mf2-grid-slot` / `.mf2-line`
- `overflow: visible` على حاويات الحبر

### مقاييس الخط (`mushaf-baseline.json`)

| ثابت | قيمة |
|------|------|
| fontSizePx (**S** ثابت) | 24.382 |
| lineHeightEm | 1.35 |
| lineGapPx | 14.078 |
| slotCount | 15 |

### شارة السورة

- `data-ornament="none"` · `data-banner-style="minimal-rule"`
- اسم مركزي + خطّان ذهبيان رفيعان فقط
- ارتفاع ≈ خانة سطر واحدة · **بلا** SVG جناح / ميدالية بتلات / أرابيسك

### رقم الصفحة والذيل

- `data-page-chrome="minimal"` · `data-page-numeral="arabic"`
- رقم عربي بسيط في الوسط (±2px) · **بلا** خرطوش SVG
- مؤشر تنزيل الخط: `data-font-progress="corner"` (ركن سفلي) · أرقام عربية ٪

### خطوط QPC

- تحميل عبر FontFace مع **`font-display: block`** لتفادي وميض المقاس قبل جاهزية الخط

### صفحتا الافتتاح

- **لا** `.mf2-opening-frame` · **لا** `OPENING_BANNER_TOP_PCT`
- نفس شبكة التدفق ١٥ صفًا كباقي الصفحات

### سلّم الخطوط من `S`

| العنصر | النسبة |
|--------|--------|
| نص / بسملة | 1.00 |
| اسم الشارة | 0.78 |
| رقم الصفحة | 0.46 |
| رأس | 0.42 |
| حزب | 0.40 |

---

## 3. قواعد التخطيط

1. **تدفق شبكة ١٥** — لا تموضع مطلق بأسطر أساس قديمة.
2. **S ثابت** من baseline — لا تحجيم ديناميكي يغيّر المقاس المرجعي.
3. **الرأس:** فقط السور التي تبدأ في الصفحة.
4. **الذيل:** رقم عربي بسيط مركزي · ≥8px عن آخر حبر.
5. **صفر تقاطع** بين حبر / شارة / بسملة / رأس / ذيل / مؤشر الخط.

---

## 4. محظورات دائمة

1. **لا تستبدل مجسماً من خط QPC بعنصر مرسوم يدويًا.**
2. **لا تُعِد الأرابيسك / الأجنحة / الخرطوش المزخرف / إطار الافتتاح.**
3. **لا `position:absolute` على خانات الأسطر.**
4. **لا `overflow: hidden` رأسيًا** على حاويات الأسطر.
5. **لا مساس** بنص القرآن أو الترقيم أو حدود الصفحات.
