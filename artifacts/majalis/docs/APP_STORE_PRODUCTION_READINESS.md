**آخر تحديث كود:** فرع `cursor/app-store-production-readiness`  
**مسار المنتج:** Capacitor حول `artifacts/majalis` → Bundle `com.yousef.majlisilm`  
**الويب الإنتاجي:** https://www.ssunnah.com

## تصنيف الوظائف (من الواقع الحالي)

### P0 — يجب أن تعمل
تشغيل التطبيق · الرئيسية · التنقل · الأقسام · البحث · فتح الدروس · تشغيل الصوت (قرآن/دروس) · مواقيت الصلاة · المصادقة/الجلسة · حفظ التقدم المحلي · API إنتاج · انقطاع الشبكة · حذف الحساب (Apple 5.1.1)

### P1 — مهم مع ملاحظات
الإشعارات المحلية/الدفع · القبلة · الروابط العميقة · المحفوظات السحابية · واجهات مخفية (`/vault`, `/car-mode`, `/mosque-mode`) · تزامن عبر الأجهزة

### P2 — بعد الإطلاق
تحسينات بصرية واسعة · ميزات غير مكتملة في السجل · توسعة Remote Config

## إصلاحات جاهزية مُنفَّذة في هذه الجولة

1. تعطيل جلسة التسجيل الأصلية (لا `.playAndRecord` بدون `NSMicrophoneUsageDescription`).
2. إزالة `NSPrivacyCollectedDataTypeAudioData` من `PrivacyInfo.xcprivacy`.
3. إغلاق أدوات تشخيص الإشعارات في الإنتاج (`import.meta.env.DEV` فقط).
4. محاذاة GPS مع Coarse Location (`enableHighAccuracy: false` للقبلة ومحدد الموقع).
5. تحديث روابط الخصوصية/حذف الحساب إلى `www.ssunnah.com` في قائمة المتجر.

## خطة الطوارئ / Rollback

| سيناريو | إجراء |
|---------|--------|
| عطل ويب حرج | إصلاح سريع على `main` → Vercel Production (التطبيق يحمّل `www.ssunnah.com`) |
| عطل أصلي في البناء | إيقاف الإصدار في App Store Connect · الإبقاء على آخر بناء TestFlight مستقر |
| رابط وسائط تالف | تعطيل/إصلاح المحتوى من المصدر دون تخمين شرعي |
| API غير متوافق | إبقاء التوافق الخلفي · رسالة صيانة عبر الصفحة/`native-load-error` |
| بلاغات | قناة الدعم في Connect + بريد الدعم المعتمد من المالك |

معرفة الإصدار: `https://www.ssunnah.com/version.json` + رقم البناء في About/الإعدادات إن وُجد.
