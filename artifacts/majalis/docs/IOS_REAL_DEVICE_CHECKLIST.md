# قائمة اختبارات تتطلب جهاز iPhone حقيقي

لا تُنفَّذ على Simulator ولا في بيئة Linux CI. تُنفَّذ يدويًا على جهاز فعلي
(يفضّل نفس إعدادات Signing الحالية دون تغيير Bundle ID / Team / Certificates)
قبل رفع TestFlight يدويًا من Xcode على macOS.

## صوت في الخلفية والقفل

- [ ] تشغيل تلاوة قرآن ≥ 90 دقيقة متصلة (شاشة مضاءة ثم مقفلة)
- [ ] Background audio مع انتقال التطبيق للخلفية
- [ ] استمرار الصوت على شاشة القفل
- [ ] أزرار Control Center (تشغيل/إيقاف/تقدّم) أثناء التلاوة
- [ ] مسار AirPods: اتصال، فصل، إعادة اتصال أثناء التشغيل
- [ ] مسار Bluetooth سيارة/سماعة: تبديل المسار دون تعليق الجلسة
- [ ] فصل سماعة الرأس السلكية أثناء التلاوة/التسميع
- [ ] مكالمة واردة أثناء التلاوة ثم استئناف/إيقاف صحيح بعد انتهاء المكالمة
- [ ] تفعيل Siri أثناء جلسة صوتية (مقاطعة ثم عودة)

## تسميع / تعرّف صوتي

- [ ] إذن الميكروفون: قبول → جلسة تسميع ناجحة برموز خطأ واضحة عند الصمت
- [ ] إذن الميكروفون: رفض → رسالة/حالة denied (لا matches فارغة صامتة)
- [ ] إذن Speech Recognition: قبول / رفض
- [ ] الانتقال المتكرر بين التلاوة (playback) والتسميع (record) دون تعارض AVAudioSession
- [ ] media services reset نادر (إن أمكن محاكاته) → رفض `MEDIA_SERVICES_RESET` ثم إعادة المحاولة

## استقرار الجهاز

- [ ] استهلاك البطارية أثناء 90 دقيقة تلاوة + جلسة تسميع قصيرة
- [ ] حرارة الجهاز بعد تشغيل طويل
- [ ] استقرار الذاكرة (لا نمو مستمر في Instruments / Xcode memory gauge)
- [ ] Cold launch / Warm launch على الجهاز
- [ ] Background → Foreground مع استعادة الجلسة (Supabase auth)
- [ ] تحديث من نسخة TestFlight أقدم إلى البناء الحالي (migration / تفضيلات / لا كراش)

## واجهة وإتاحة على الجهاز

- [ ] RTL عربي
- [ ] Dark Mode
- [ ] Dynamic Type (أكبر حجم نص)
- [ ] VoiceOver على الشاشات الحرجة (مصحف، صلاة، تسميع)
- [ ] Deep Links: `majlisilm://…` و Universal Links `https://majlisilm.com/…`

## موافقات يدوية (خارج الوكيل)

- [ ] Archive مُوقَّع بإعدادات Signing الحالية فقط (لا تغيير Team/Bundle/Profiles)
- [ ] رفع TestFlight يدويًا من Organizer (ممنوع الرفع التلقائي من الوكيل)
- [ ] مراجعة إجابات App Privacy في App Store Connect مقابل `PrivacyInfo.xcprivacy` وInfo.plist
- [ ] (اختياري لاحقًا) نقل تخزين جلسة Supabase من WebView storage إلى Keychain — غير مطبّق في هذه المرحلة
