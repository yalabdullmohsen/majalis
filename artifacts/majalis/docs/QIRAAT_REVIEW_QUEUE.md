# طابور مراجعة القراءات — QIRAAT_REVIEW_QUEUE

آخر تحديث: 2026-08-17

## الغرض

كل مادة قراءات (وصف خلاف، سند، فرش حرف، أصل أدائي، أو اقتراح عرض صوتي) لم تُراجع بعد من مصدر معتمد (`النشر` / `التيسير` / `الشاطبية` / `الدرة`) تُدرج هنا.

**لا تُعرض في الواجهة كحقيقة قطعية** حتى تُنقل من هذا الطابور إلى الكتالوج المراجع (`src/lib/quran-qiraat/catalog.ts`) مع حقل `source` صريح.

## قواعد الإدراج

| الحقل | مطلوب |
|---|---|
| الموضوع / الموضع (سورة:آية) | نعم |
| نوع الخلاف (`harf` / `harakah` / `lahji` / أصل) | نعم |
| المصدر المقترح للمراجعة | نعم |
| من أضافه وتاريخ الإضافة | نعم |
| ملاحظة (لماذا غير مؤكد؟) | نعم |

## قيد العرض

- مصحف المنصة = **حفص فقط** (`MUSHAF_TEXT_IS_HAFS_ONLY`).
- أي وجه لغير حفص يُذكر **وصفًا** («قرأ فلان كذا») ولا يُستبدل به نص المصحف.
- `QIRAAT_AUDIO_CATALOG` فارغ عمدًا حتى تُراجع التراخيص والمصادر.

## الطابور الحالي

_لا عناصر معلّقة._
