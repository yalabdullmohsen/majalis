# تقرير نظام الأذان والتنبيهات (احترافي)

## سبب انقطاع الأذان سابقًا
- نظام iOS يقطع صوت الإشعار المحلي عند ~٣٠ ثانية.
- ملف أذان طويل كصوت إشعار واحد ينقطع حتمًا.
- مسار الدخول كان يُجدول مرتين أحيانًا (إشعار enter + مقاطع متتابعة) فيظهر تكرار وتشويش.

## ما أُصلح في الجدولة
- معرّفات ثابتة منطقيًا لكل صلاة: `fajr` / `dhuhr` / `asr` / `maghrib` / `isha` (مع hash رقمي مستقر لـ Capacitor + `friendlyKey`).
- قبل إعادة الجدولة: حذف معلّقات الصلاة فقط (ومقاطع الأذان) عبر مسح pending ذات `prayer-*` / `adhanSegment`.
- على iOS في الوضع الكامل: مقاطع الأذان هي إشعار الدخول — لا يُجدول enter مكرر من `prayer-local-notifications`.
- سجل تشخيص `[adhan/debug] pending after reschedule` يعرض العدد والعينة.

## كيف يعمل الأذان الكامل الآن
1. **التطبيق مفتوح (واجهة):** تشغيل الملف الكامل عبر مشغّل الأذان داخل التطبيق، مع إلغاء بقية مقاطع الإشعار.
2. **الشاشة مقفلة / التطبيق مغلق:** إشعار قصير مضمون، أو حتى ٤ مقاطع CAF متتابعة (≤٢٨ث) لمكة/الحرم ثم إكمال عند فتح التطبيق.
3. **المختصر:** إشعار واحد بصوت CAF قصير (لا يُسمّى كاملًا).

## حدود iOS التي لا تُتجاوز
- صوت الإشعار ≤ ~٣٠ث.
- الصامت / Focus قد يكتمان الصوت بلا Critical Alerts.
- مؤقّتات JS تتوقف في الخلفية؛ لذلك الإشعارات المحلية هي مصدر الاعتماد بعد الإغلاق.
- يُنصح بفتح التطبيق دوريًا لتحديث المواقيت وإعادة الجدولة.

## واجهة المستخدم
- صفحة «تنبيهات الصلاة والأذان» + «مساعدة الأذان والتنبيهات».
- مدد التنبيه السابق: 5 / 10 / 15 / 30 دقيقة.
- نصوص: «أذان المغرب» / «حان وقت صلاة المغرب» / «اقترب وقت المغرب».
