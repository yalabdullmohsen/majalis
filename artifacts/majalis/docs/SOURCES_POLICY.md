# سياسة مصادر الدروس والحلقات

## المبدأ
المحتوى **مملوك لأصحابه**. المجلس العلمي **لا يعيد استضافة** محتوى الجهات الخارجية، بل يعرض:
- العنوان والبيانات الوصفية (شيخ، مكان، وقت، نوع النشاط)
- رابط المنشور الأصلي
- رابط التسجيل إن وُجد

## إزالة حساب
لطلب إزالة حساب من الدليل أو إيقاف الحصاد:
1. افتح issue في المستودع مع اسم الحساب والمنصة
2. أو راسلنا عبر صفحة [اتصل بنا](https://majlisilm.com/contact)

سنُعطّل الحساب (`enabled: false`) في `public/data/sources/accounts.json` خلال ٧ أيام عمل.

## إنستغرام
لا نستخدم كشطاً يخالف شروط المنصة. الاستيعاب عبر:
- `inbox.jsonl` (روابط منشورات يدوية — وضع `oembed`)
- مزوّد مرخّص (`INSTAGRAM_PROVIDER_KEY` + `INSTAGRAM_PROVIDER_ENDPOINT` — وضع `provider`)

## Telegram و Web
- **Telegram:** قنوات عامة عبر `t.me/s/{channel}`
- **Web:** RSS إن وُجد، وإلا جلب مهذب لـ og:title/description (يحترم robots.txt عبر User-Agent معرّف)

## منع التكرار
لا يُنشر الإعلان مرتين. التكرار يُكتشف عبر `post_url` و`external_id` وعنوان مُطبَّع + تاريخ + مكان.
إن تكرر من أكثر من حساب → بطاقة واحدة بمصادر متعددة.

## إخلاء مسؤولية
المجلس العلمي وسيط روابط وإعلانات علمية فقط، ولا يتحمل مسؤولية محتوى الجهات الخارجية.
