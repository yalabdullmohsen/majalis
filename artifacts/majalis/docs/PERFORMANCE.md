| مقياس | مقيس (dist محلي) | الهدف | حالة |
|--------|------------------|--------|------|
| JS رئيسي `index-*.js` gzip | **~135 KB** | <250 KB ابتدائي | مقبول للقطعة الرئيسية؛ الحزمة الكلية فوق الهدف بسبب بذور محتوى كسولة |

## قرارات
1. code-splitting على مستوى المسار قائم عبر `lazyWithRetry` في `App.tsx`.
2. SW: network-only للتنقلات؛ كاش بيانات/أذكار؛ مربوط بـ`SW_BUILD_ID`.
3. CSS الحرج: أُخرجت أنماط الصفحة/المساعد/المصادقة الثقيلة إلى CSS كسول مع المكوّنات.
4. الخطوة التالية: قياس Lighthouse وخفض بذور المحتوى في المسار الحرج.
