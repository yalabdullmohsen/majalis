## أ-١ — بحث مواضع إزاحة الإطار (قبل التعديل)

| الملف | السطر / الرمز | القيمة / الدور | هل يقيّد؟ |
|--------|----------------|-----------------|-----------|
| `MushafPageV2.tsx` | `OPENING_FRAME_TOP_OF_BODY` / `BOT` | كان القياس يُبلَّغ على `.mf2-lines` فقط | لا clamp |
| `MushafPageV2.tsx` | `measure()` → `[data-opening-frame]` | بعد الإصلاح: `top`/`bottom` بالبكسل نسبةً لـ `.mpv-body--ayah` | لا |
| `mushaf-v2.css` | `.mf2-opening-frame { top/bottom: 9% }` | نسبة من الحاوي `.mf2-lines` (احتياطي قبل القياس) | CSS % على الخطوط لا الجسم |
| `OpeningPageFrame.tsx` | SVG إطار | لا يضبط الإزاحة | — |
| `quran.css` | `.mpv-body.mpv-body--ayah { padding-top: max(8px, calc(var(--inset-top)+0.95rem)) }` | يغيّر ارتفاع/أصل كتلة الصفحة | يؤثر على النسبة من الجسم |
| `quran.css` | `.mpv-ayah-header` مطلق أعلى الجسم | يغطي جزءًا من `.mf2-lines` | يجعل نسبة الخطوط ≠ نسبة الجسم |
| `mushaf-baseline.json` | `topOffsetPct: 0` | للصفحات العادية فقط | **لا يرثه** إطار الافتتاح |
