**حالات الإذن:**
- **ممنوح** — استخدام مسموح موثّق (ترخيص مفتوح أو إذن كتابي أو ملك عام مؤكد).
- **جزئي** — استخدام مقيّد مسموح حاليًا (بث حي + إسناد) دون إعادة توزيع مجمّعة.
- **مطلوب** — يلزم إذن/تأكيد قبل شحن المتجر بهذا الشكل.
- **غير محسوم** — لا يكفي التوثيق الحالي؛ يُعزل من الإطلاق أو يُستبدل.
- **معطّل عمدًا** — البنية موجودة والمحتوى فارغ/موقوف حتى التوثيق.

## ٣) ما أُزيل أو وُقِف قبل النشر

| البند | الإجراء |
|---|---|
| صور مصحف المدينة | لم تُورد أصلًا — مسار QPC فقط |
| تفسير صوتي | كتالوج فارغ + remote kill-switch |
| نسبة شخصية للأذان | موقوفة — عرض النمط فقط |
| حزم MP3 تلاوة في الثنائي | ممنوعة بالسياسة |
| كتب بلا مصدر موثّق | تُعرض «قيد المراجعة»؛ لا تُسوَّق كمرخّصة |
| خطوط QPC في IPA بعد sync | `native:strip-qpc-fonts` يقلّل الشحن؛ التنزيل عند التشغيل |

**ما لم يُحذف بعد (يحتاج إذنًا قبل المتجر):** خطوط QPC في مستودع الويب، بث التلاوات، جلب التفاسير، مقاطع الأذان المضمّنة، نصوص مستندة لحصن المسلم، فهرس المكتبة غير المصدَّر.
