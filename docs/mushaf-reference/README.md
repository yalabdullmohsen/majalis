# مراجع بصرية — تطبيق آية

هذا المجلد يحتوي على صور مرجعية من تطبيق **آية** للمصحف الشريف.

## المحتويات المطلوبة

- `aya-001.png` — الصفحة 1 (الغلاف)
- `aya-002.png` — الصفحة 2 (البسملة + نهاية سورة الفاتحة) ⚠️ مهمة جداً للتشخيص
- `aya-003.png` — صفحة عادية (للمقارنة)
- `aya-004.png` — صفحة عادية أخرى
- `aya-283.png` — صفحة المعايرة (تُستخدم لحساب حجم الخط)
- `aya-600.png` — صفحة متقدمة (تحتوي على وصف حزب)


## ملاحظات

- هذه الصور تُعتبر **مصدر الحقيقة** (source of truth)
- أي تغيير في التخطيط يجب أن يطابقها ضمن ±1.5%
- تُستخدم في اختبارات Playwright للتحقق البصري
