## أ) نظام الإحداثيات والمقياس

### النسق الواحد (Golden Ratio Layout)
```
┌─────────────────────────────┐
│ الصفحة المنطقية             │
│ العرض: 1000 وحدة           │
│ الارتفاع: 1618 وحدة         │
│ النسبة: 1:1.618 (ذهبية)    │
└─────────────────────────────┘
```

| المعيار | القيمة | الوحدات | ملاحظات |
|--------|--------|---------|---------|
| عرض الصفحة | 1000 | unit | نسبة ذهبية مع الارتفاع |
| ارتفاع الصفحة | 1618 | unit | 1000 × φ |
| نسبة الجهاز (مثال: 390px) | min(availW/1000, availH/1618) | k | معامل التحجيم الموحد |

### معادلة التحجيم (Transform Scale)
```css
transform: scale(k) /* k = min(availableWidth/1000, availableHeight/1618) */
transform-origin: top center;
```

**الهدف:** أي صفحة على أي دقة تُعطي نفس التخطيط المنطقي بعد القسمة على `k`.

## ج) عناصر التصميم الثابتة

### 1) الشارة (Surah Banner)
```
📏 المواضع (من aya-*.png):
  - الموضع الرأسي: Y من أعلى الصفحة (%)
  - الارتفاع: H% من ارتفاع الصفحة
  - العرض: 100% عرض عمود الحبر
  - الهامش الأفقي: M% من اليسار/اليمين
```

**البناء:**
- خلفية SVG تزيينية (أرابيسك متماثل) ← `surah-banner.svg` (ملف واحد ثابت)
- لوحة وسطى فاتحة بإطار ذهبي مزدوج
- اسم السورة (خط عثماني مشكَّل) في الوسط
- زهرتان متماثلتان بالأطراف
- لون الذهب: `#D4AF37` (أو من المرجع)
- حجم النص: من `MUSHAF_SPEC` (مثلاً 48 unit)

**الملف:**
```
src/features/mushaf/components/SurahBanner.jsx
src/assets/surah-banner.svg (غير قابل للتعديل برمجياً)
```

### 2) علامات الآيات (Verse Markers)
```
📏 المواضع (من aya-*.png):
  - القطر: D% من ارتفاع الصفحة
  - الموضع داخل السطر: baseline + offset
  - اللون: ذهبي مملوء (#D4AF37)
```

**البناء:**
- ميدالية دائرية (circle) مملوءة
- أرقام عربية (٠، ١، ٢، ... ٦٠٤)
- محاذاة عمودية: baseline
- لا توسيع ديناميكي أو تأثيرات
- استخدم `<svg>` inline أو كمكون

### 3) الرأس (Header)
```
[الجزء N]              [اسم السورة(ة)]
```
- الموضع: أعلى الصفحة (Y_header من المرجع)
- الحجم: من المرجع (مثلاً 14 unit)
- اللون: ذهبي باهت (`#B8860B` أو مشابه)
- الخط: نفس qpc-v2 بحجم أصغر

### 4) الذيل (Footer / Colophon)
```
        [خرطوش رقم الصفحة]
[وصف الحزب]             [معلومات النسخة]
```
- الخرطوش: ملف SVG أو رسمة CSS محددة (من المرجع)
- رقم الصفحة: أرقام عربية داخل الخرطوش
- وصف الحزب (مثلاً "ثلاثة أرباع الحزب 60"): نص بحجم صغير
- الموضع: أسفل الصفحة

### 5) اللون والخلفية
| العنصر | القيمة | الملاحظات |
|--------|--------|---------|
| خلفية الصفحة | #F5EAD8 (عاجي) | أو من aya-*.png |
| لون الحبر | #1A1A1A (أسود عميق) | مقاس من المرجع |
| ذهبي (عناصر) | #D4AF37 | للشارة والعلامات والرأس |
| ذهبي باهت | #B8860B | للرأس والنصوص الثانوية |

## د) منطق الصفحة (Page Engine)

### البيانات المُدخلة
```javascript
const page = {
  pageNumber: 2,
  textLines: [
    { words: ["الحمد", "لله", ...], lineNumber: 0 },
    { words: [...], lineNumber: 1 },
    // ... 15 سطر أو أقل
  ],
  surah: { name: "سورة الفاتحة", number: 1 },
  juz: 1,
  hazbDescription: null, // أو "ثلاثة أرباع الحزب 60"
}
```

### الحسابات المُحظورة (FORBIDDEN)
```javascript
❌ calculateFontSizeByPage(pageNumber)    // لا! استخدم الثابت
❌ clamp(..., 'vw')                       // لا vw/vh/dvh
❌ useEffect(() => {
     const size = window.innerWidth * 0.05;
     setFontSize(size);
   })                                     // لا تحسبه ديناميكياً!
❌ @media (max-width: 600px) { ... }     // لا media queries
❌ word-spacing, letter-spacing (للتمدد) // استخدم scaleX فقط
```

### الحسابات المسموحة
```javascript
✅ lineHeight = (inkBlockHeight / 15) // ثابت من المرجع
✅ baseline[i] = topMargin + (i * lineHeight) + baselineOffset
✅ scaleX = [0.94, 1.06] // فقط للتمدد الأفقي
✅ transform: scale(k) على الحاوية
✅ padding داخل خانة السطر (ثابت)
```

## ك) الملخص: ما الذي يُمنع؟

| ممنوع | السبب | الحل |
|--------|--------|--------|
| `font-size: clamp()` | تغيير ديناميكي | ثابت + transform |
| `vw`, `vh`, `dvh` | نسب نسبية | 1000×1618 وحدة ثابتة |
| `@media` queries | اختلاف حسب الجهاز | معامل `k` موحد |
| `useEffect` + `window.innerWidth` | حسابات ديناميكية | ثابت منذ البداية |
| `word-spacing` التكيفي | اختلاف السطور | `transform: scaleX` فقط |
| padding/margin نسبي | تباين عمودي | شبكة صلبة |
| border-radius ديناميكي | عناصر متغيرة | ثابت |
| SVG توليدي | تغيير عشوائي | ملف واحد ثابت |
