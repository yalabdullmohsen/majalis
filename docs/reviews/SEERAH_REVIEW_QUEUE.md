# طابور مراجعة السيرة (SEERAH_REVIEW_QUEUE)

مصدر الطابور: PR #956 — **لا يُدمَج قبل مراجعة المالك**.

صيغة الحكم المطلوب لكل بند: `يُثبت` | `يُحذف` | `يُعرض مع بيان الخلاف`.

| 9 | `rq-badr-numbers` | أعداد المقاتلين في بدر | صحيح البخاري/مسلم + مغازي ابن إسحاق المحرّرة | الأعداد التقريبية مما تتداوله كتب السيرة؛ يلزم توحيد رقم مع مصدر محرَّر أو الإشارة للخلاف. |  |
| 10 | `rq-qaynuqa` | تفاصيل جلاء بني قينقاع | مغازي ابن إسحاق / ابن هشام بعد تخريج التفاصيل | الخبر معروف في المغازي؛ التفاصيل تحتاج إحالة دقيقة قبل إدراجها كحدث مستقل. — مرشّح لحدث لاحق بعد استكمال المراجع. |  |

| 12 | `rq-letters-kings` | رسائل الدعوة إلى الملوك | كتب السيرة والدلائل — تخريج كل رسالة على حدة | ثابت المعنى في الجملة؛ تفاصيل كل رسالة ونصّها يحتاجان تخريجاً منفرداً. |  |

| 14 | `rq-farewell-count` | عدد حجيج حجة الوداع | صحيح مسلم وغيره — الجمع العظيم دون رقم قاطع | اختلفت الروايات في تقدير العدد؛ يُذكر الجمع العظيم دون الجزم برقم. |  |
| 15 | `rq-kitab-sunnah-wording` | لفظ «كتاب الله وسنتي» في الخطبة | بيان طرق الحديث وضعف كثير منها عند أهل الحديث | المعنى بالاعتصام بالكتاب ثابت؛ اللفظ المشهور مروي بطرق تُضعَّف عند كثير من أهل الحديث. |  |
| 16 | `rq-death-day` | تعيين يوم الوفاة في ربيع الأول | كتب السيرة مع بيان الخلاف ومنع الشعائر المحدثة | المشهور ١٢ ربيع الأول مع خلاف؛ لا يُقطع به ولا تُشرع شعائر عليه. |  |
| 17 | `rq-tabuk` | غزوة تبوك كحدث مستقل في الخريطة | الصحيحان + مغازي — بطاقة حدث بعد استكمال المصادر | ثابتة في الصحيح والمغازي؛ لم تُدرج بعد في SEERAH_EVENTS — تُضاف عند استكمال بطاقة مصادرها. — أولوية متوسطة للتوسعة التالية. |  |

## قواعد
- ما لم يُراجَع لا يُعرض في التطبيق.
- لا يُحذف من المستودع قبل قرار المالك.
