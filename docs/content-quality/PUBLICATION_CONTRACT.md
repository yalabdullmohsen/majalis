## الحالات

| Status | يظهر للعامة؟ | ملاحظة |

| `REVIEW_REQUIRED` / حالات مراجعة بشرية | لا | لا تُحوَّل آليًا إلى منشور |
| `BLOCKED_LICENSE` | لا | حاجز ترخيص |
| `PUBLISHED` | نعم | بعد قرار بشري + مصدر + أهلية المجال |
| `REJECTED` | لا | مرفوض |

## قواعد ملزمة

1. لا يظهر للعامة إلا `PUBLISHED`.
2. `SOURCE_VERIFIED` لا تعني تلقائيًا `PUBLISHED`.
3. `REVIEW_REQUIRED` لا تُنشر آليًا، ولا نتيجة ذكاء اصطناعي تُعد مراجعة شرعية.
4. لا Enums للمستخدم في الواجهة العامة.
5. لا طوابير مراجعة ولا أزرار فلترة/مشاركة/تحدٍ في قسم بلا منشور.
6. لا عرض «0 سجل منشور» ولا ادّعاء اكتمال بلا بيانات.
7. Stub ≠ مادة مكتملة.
8. البحث وSEO وsitemap وRelated Content تتبع المنشور فقط.
