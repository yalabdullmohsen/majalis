## جرد سابق لا تخمين

- ملفات CSS غير المستوردة (`elite-2026` ~280KB، `majalis-v2`، `modern-2026`، `patterns`…) حُذفت في #930 — ليست على القرص.
- `cssCodeSplit: true` مفعّل. معظم المسارات `lazy()` أصلًا.
- QPC V2 (604 ملفًا) تُحمَّل عبر `FontFace` في `useQpcPageFont` للصفحة الحالية وجارتيها فقط.
- العائق الأكبر للرسم الأول: Google Fonts في `index.html` + preload خط المصحف على كل الصفحات + تسخين Amiri Quran عند idle عام.

## المرحلة 2 — خطوط الإقلاع (`perf/fonts-boot`)

**ما تغيّر**

- إزالة `fonts.googleapis.com` و`fonts.gstatic.com` من `index.html` ومن CSP.
- قالب `generate-seo.mjs` (صفحات prerender) يُحدَّث في دفعة لاحقة حتى لا يُفتح PR بـ ٩٥٤ ملف HTML مولَّد.
- استضافة Amiri / Noto Naskh / Aref Ruqaa / Scheherazade New محليًا (`public/fonts/ui/*.woff2`، SIL OFL) مع تقسيم unicode-range عربي/لاتيني.
- preload واحد: `/fonts/ui/amiri-400-ar.woff2`.
- `preconnect` واحد: أصل Supabase.
- بديل مقاييس `MajlisFallback` في `--font-app` (بدون تغيير أسماء العائلات المستخدمة في الواجهة).
- تسخين خطوط المصحف (`warmStaticQuranicFonts`) انتقل من `main.tsx` إلى `MushafReaderPage` — لا تنزيل Amiri Quran على الرئيسية.
- صفر تغيير مقصود في الألوان أو الأحجام أو بوابات المصحف.

**قياس**

- قبل: Google CSS + preload مصحف على كل صفحة.
- بعد: يُقاس بوسيط 3 تشغيلات PSI على الإنتاج بعد الدمج. المتوقع: انخفاض FCP/LCP وحظر العرض المرتبط بالخطوط، وثبات SEO.

**قرار**

- الإبقاء على أسماء `Amiri` / `Noto Naskh Arabic` / `Aref Ruqaa` بدل عائلة `MajlisArabic` الموحّدة حتى لا ينكسر الشكل.
- عدم جعل الرئيسية فورية في هذا الفرع (ميزانية JS ≤164KiB).
- عدم تفكيك `index.css` هنا (دفعة لاحقة ≤40 ملفًا).
