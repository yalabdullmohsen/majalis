# بروتوكول تسريع الوكيل (AGENT THROUGHPUT)

يُطبَّق في كل مهمة. التفاصيل والقياس: `docs/CI_THROUGHPUT.md`. الفهرس: `docs/REPO_INDEX.md`.

## مطلق

1. **ممنوع انتظار CI.** لا `gh run watch`، لا حلقات `sleep`، لا «أنتظر Verify». البوابة = تحقق محلي.
2. بعد نجاح المحلي: ادفع → افتح PR Ready → `auto --squash` → **انتقل فورًا للمهمة التالية**.
3. الفحص المطلوب للدمج = **Verify build** وحده.
4. فروع متراكمة من رأس الفرع السابق عند الحاجة؛ لا تنتظر دمج السابق.
5. دفعة = مرحلة كاملة (٥–١٥ إصلاحًا متجانسًا) ضمن ≤٤٠ ملفًا و≤٤٠٠ سطر حذف.
6. خيط بلا إغلاق خلال محاولتين أو ١٥د → `docs/DECISIONS_PENDING.md` واقفز.
7. قرار بشري (PWA/تراخيص/CSP) لا يوقف الطابور — سجّل واقفز.

## استكشاف

- ابدأ من `REPO_INDEX.md`؛ ممنوع مسح الشجرة كاملًا.
- `rg` محدد + قراءة نطاق أسطر؛ لا إعادة قراءة ملف في نفس الجلسة بلا سبب.
- قبل أي حذف مسار: `rg` على الكود وsitemap وprerender؛ ما في sitemap/prerender لا يُحذف بلا حذف مدخله في نفس الـcommit.

## تحقق محلي

- أثناء العمل: اختبارات المرحلة + `tsc` تزايدي إن لزم.
- نهاية الدفعة فقط: build كامل للويب (`@workspace/majalis`).
- pitch/promo/mockup مستبعدة أصلًا من typecheck/build الجذري.

## إخراج

- التقارير في `docs/`؛ رسالة المحادثة ≤٣ أسطر: ما دُفع/PR · الأرقام · التالي.
